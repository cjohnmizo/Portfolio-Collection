# Bootstrap Portfolio Collection

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A collection of **10 unique, production-ready portfolio templates** built with Bootstrap 5.3+.
Designed for developers, designers, photographers, and founders.

<!-- Created by cjohnmizo - Authorized -->

## 🚀 Quick Start

1.  **Clone or Download** this repository.
2.  Open `index.html` in your browser to view the gallery of all templates.
3.  Choose your favorite template from the `bootstrap-portfolio-collection/templates/` folder.
4.  Copy the template folder (e.g., `bootstrap-portfolio-collection/templates/01-minimalist`) to a new location to start your project.

## 🛠 Tech Stack

- **Framework**: Bootstrap 5.3+ (CDN)
- **Icons**: Bootstrap Icons (CDN)
- **Fonts**: Google Fonts (CDN)
- **JS**: Minimal Vanilla JS (No jQuery)
- **Build Tools**: None required! Just HTML/CSS/JS.

## 🎨 Customization

Each template is designed to be easily customizable.

1.  **Open `index.html`** in your code editor.
2.  **Look for the Config Comment** at the top of the file for quick edit locations.
3.  **Replace Images**: Replace the SVG placeholders in `assets/img/` or update the `src` attributes to point to your own images.
4.  **Update Text**: Change names, titles, and project descriptions directly in the HTML.
5.  **Modify Colors**: Edit `assets/css/style.css` to override Bootstrap variables or add custom styles.

## 🌍 Deployment

Since these templates are static HTML/CSS/JS, you can deploy them anywhere for free:

- **Netlify**: Drag and drop your template folder to the Netlify dashboard.
- **GitHub Pages**: Push your code to a GitHub repo and enable Pages in settings.
- **Vercel**: Import your Git repo and deploy.
- **Shared Hosting**: Upload the files via FTP to `public_html`.
